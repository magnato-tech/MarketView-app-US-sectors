# Local Factory Storage

This folder stores local-first persistence for the AI Trading Bot Factory.

Generated files:

- `bots.json`: Bot DNA documents
- `evaluations.json`: Backtest/evaluation snapshots
- `evolution-log.json`: Evolution events (spawn, retire, mutate, crossover)
- `factory-state.json`: Active population and cycle settings

These files are generated by `LocalFileBotRepository`.
They are intentionally local runtime artifacts and should not contain secrets.
